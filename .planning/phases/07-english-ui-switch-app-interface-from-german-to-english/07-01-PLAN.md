# Plan 07-01 — App shell, auth screen, and all validation messages

<objective>
Translate the parts every other screen inherits: the HTML shell and metadata, the
login screen, the navigation/logout, the home page, and every Zod validation
message in `lib/validations/*`. Doing this first means later plans never have to
revisit shared copy.
</objective>

<constraints>
**These MUST stay German — they are not UI copy:**
- `lib/laufliste/**` and `lib/cogs/resolve.ts` — their strings are rendered into the
  Laufzettel PDF, which German authorities read.
- `lib/bundesland.ts` — the 16 Bundesland names are proper nouns.
- `lib/extraction/prompt.ts` — already English; its German words are example VALUES
  that steer Claude's extraction. Do not touch this file.
- Authority names/addresses/notes and document-type display names from the DB.

**No i18n library.** Replace the German string literals with English ones in place.
</constraints>

<must_haves>
- `app/layout.tsx` declares `lang="en"` and carries an English description
- Login screen, its errors, and the logout control read in English
- Navigation labels and the home page read in English
- Every Zod message in `lib/validations/{auth,case,review,admin}.ts` is English
- The login error stays a single generic message (no user enumeration)
- `npx tsc --noEmit` passes and `npx vitest run` shows no NEW failures
</must_haves>
