# Plan 07-05 — Final sweep and human verification

<objective>
Prove the phase goal: every operator-facing screen is English, and every German
artefact that leaves the app is untouched. Catch stragglers the per-area plans
missed.
</objective>

<must_haves>
- No German UI string remains anywhere under `app/` or `components/`
- The Laufzettel PDF is byte-for-byte equivalent in content to before the phase
- Authority resolution returns identical results to before the phase
- Full build and test suite show no NEW failures
</must_haves>

<task id="07-05-01" type="auto">
<action>
Sweep for leftovers. Run:

```
grep -rnE "[äöüß]" app components --include="*.tsx" --include="*.ts" | grep -v "\.test\."
```

Every hit must be one of:
  (a) a line that renders a DB value (authority/doc-type/chamber/Bundesland), or
  (b) the product term "Laufzettel", or
  (c) a German word inside a code identifier or DB column name
      (`dokumenten_typ`, `behoerdenAuthority`, `bundesland`, …).

Anything else is a missed translation — fix it.

Then sweep for German words without umlauts that the umlaut grep misses:

```
grep -rnE "\"(Bitte|Speichern|Abbrechen|Hochladen|Herunterladen|Suchen|Zur|Neue[rs]?|Keine|Wird|Fehler|Erfolg|Datum|Name der)" app components --include="*.tsx" --include="*.ts" | grep -v "\.test\."
```

Fix any remaining hits.
</action>
