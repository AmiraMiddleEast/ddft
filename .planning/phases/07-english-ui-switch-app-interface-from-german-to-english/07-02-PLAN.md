# Plan 07-02 — Upload, document detail, and review flow

<objective>
Translate the operator's core daily path: upload → document detail → review →
authority result. This is the highest-traffic surface of the app.
</objective>

<constraints>
Same as 07-01. Additionally, in this plan specifically:
- `AuthorityResultPanel` renders authority NAME, ADDRESS, OFFICE HOURS and
  SPECIAL RULES that come from the database. Translate only the surrounding
  labels and status copy; render the DB values verbatim.
- `ReviewForm`'s document-type and Bundesland dropdown OPTIONS come from the DB
  and stay German. Only the label, placeholder and helper text change.
- Do not rename `FieldName` keys (`dokumenten_typ`, `ausstellende_behoerde`,
  `ausstellungsort`, `bundesland`, `ausstellungsdatum`, `voller_name`) — they are
  DB column values and resolver inputs.
</constraints>

<must_haves>
- Upload screen, its progress rows and every error message read in English
- Document detail (extracted fields table, replace-scan dialog) reads in English
- Review screen — labels, confidence badges, buttons, discard dialog — reads in English
- Authority result panel reads in English while showing German authority data verbatim
- Field labels still map to the same `FieldName` keys
- `npx tsc --noEmit` passes; no NEW test failures
</must_haves>
